# Escopo do Projeto MESAFARTAI

## Problema de Negócio

O projeto MESAFARTAI busca auxiliar na logística de doações de alimentos, facilitando a comunicação entre doadores e organizações não governamentais (ONGs).

A solução utiliza Inteligência Assistiva e Processamento de Linguagem Natural (NLU) para compreender mensagens dos usuários e identificar informações relacionadas às doações.

## Público-Alvo

### Doadores

Pessoas, supermercados, restaurantes e outros estabelecimentos que possuem alimentos disponíveis para doação.

### ONGs

Organizações não governamentais que recebem as doações e realizam a distribuição dos alimentos.

## Escopo do Chat

O sistema deverá trabalhar com mensagens relacionadas a:

- Cadastro de doações.
- Tipo de alimento.
- Quantidade disponível.
- Data de validade.
- Localização do doador.
- Necessidade de alimentos pelas ONGs.

## Dados Coletados

Durante a conversa, poderão ser identificados dados como:

- Nome do usuário.
- Tipo de usuário.
- CEP.
- Telefone.
- Descrição do alimento.
- Quantidade em quilogramas.
- Data de validade.

## Prompt utilizado para geração da logo

Crie uma logo simples e moderna para o projeto MESAFARTAI, combinando elementos relacionados à doação de alimentos, solidariedade, tecnologia assistiva e Inteligência Artificial. A imagem deve transmitir a ideia de combate à fome, conexão entre doadores e ONGs e uso de tecnologia.
