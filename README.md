# MESAFARTAI – Logística e Inteligência Assistiva no Combate à Fome

## Descrição do Projeto

O MESAFARTAI é um projeto de tecnologia desenvolvido em Python com o objetivo de utilizar Inteligência Assistiva e Processamento de Linguagem Natural (NLU) para auxiliar na logística de doações de alimentos.

A solução busca facilitar a comunicação entre doadores e organizações não governamentais (ONGs), permitindo o cadastro de doações e o direcionamento dos alimentos para organizações que necessitam desses recursos.

O projeto utiliza tecnologias como NLU, Regex, SQLite3 e algoritmos de Machine Learning para apoiar o processo de identificação, organização e direcionamento das doações.

## ODS 2 – Fome Zero e Agricultura Sustentável

O projeto está alinhado à ODS 2 da ONU – Fome Zero e Agricultura Sustentável, buscando contribuir para o combate à fome por meio da utilização da tecnologia na organização e distribuição de alimentos.
